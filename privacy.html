Privacy Policy

AIFromZeroToHero Uploader · Last updated: October 3, 2026

Who this applies to

AIFromZeroToHero Uploader is a private tool operated by a single person, the owner of the AI From Zero to Hero YouTube channel. It is not offered to the public, and the only account that ever signs in to it is the owner's own.

What the tool accesses

When the owner signs in, the tool asks Google for one permission: to upload videos to the owner's YouTube channel (the youtube.upload scope). It uses that permission only to upload videos that the owner has reviewed and approved, along with their titles and descriptions.

What the tool does not do

  • It does not read the owner's private videos, comments, messages, or email.
  • It does not collect personal information from viewers, subscribers, or visitors.
  • It does not sell, rent, or share any data with third parties, and it does not use data for advertising.

How sign-in credentials are stored

The sign-in token that lets the tool upload is stored on the owner's own computer, in a restricted account that other programs on that computer cannot read. It is not sent to any other service.

Revoking access and deleting data

The owner can revoke the tool's access at any time at myaccount.google.com/permissions, and can delete the stored token from their computer. Videos already uploaded can be managed or deleted in YouTube Studio.

Google API Services User Data Policy

This tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

This tool uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.
